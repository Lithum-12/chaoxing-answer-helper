# 学习通自动答题助手 Next

**Tampermonkey 脚本，无需安装任何环境。**

> 抓取学习通题目 → 调用 AI 自动作答。支持多家供应商、按题型选模型、答题记录导出与 Token 统计，配可拖动的悬浮工具球与实时日志。

> 由 [long-0000/chaoxing-answer-helper](https://github.com/long-0000/chaoxing-answer-helper) Fork，本仓库为二次开发版（Next）。

---

## 安装

### 1. 安装 Tampermonkey

| 浏览器 | 方式 |
|--------|------|
| Edge | 应用商店搜索 **Tampermonkey** |
| Chrome | Chrome 网上应用店搜索 **Tampermonkey** |
| Firefox | 附加组件搜索 **Tampermonkey** |

### 2. 添加脚本

1. 打开 Tampermonkey → **添加新脚本**
2. 删除默认内容，粘贴 `chaoxing-answer.user.js` **全部内容**
3. `Ctrl+S` 保存

---

## 快速开始

| 步骤 | 操作 |
|------|------|
| ① | 打开学习通作业 / 考试页面 |
| ② | 右上角出现蓝色圆形**悬浮按钮**，鼠标悬停或点击 → 向下展开菜单 |
| ③ | 点 **⚙ 更多 / 设置** → **模型配置**，填入供应商 **API Key** 并保存 |
| ④ | 回到悬浮按钮，点 **▶ 开始答题** |
| ⑤ | 可随时点 **■ 停止** 中断 |

> 悬浮按钮可**拖动**，位置自动记忆。

---

## 界面

### 悬浮按钮（FAB）

右上角圆形按钮，向下展开为竖排菜单：

| 按钮 | 说明 |
|------|------|
| 开始答题 | 启动自动答题 |
| 停止 | 中断当前流程 |
| 调试 | 查看题目抓取情况（不自动填写） |
| 更多 / 设置 | 打开控制台 |

按钮带进度徽标与状态点（绿=正常 / 黄=进行中 / 红=错误）。

### 实时日志浮窗

有日志输出时，**右下角自动弹出**深色日志框，实时显示运行信息；点 `×` 关闭，直到下一条日志到来才会再次出现。

### 控制台标签页

| 标签页 | 功能 |
|--------|------|
|  仪表盘 | 总 Token、答题数、预估费用，含环形图与折线图 |
|  Token 分析 | 输入 / 输出 Token 明细 |
|  题目导出 | 导出答题记录（JSON / CSV / TXT / HTML） |
|  模型配置 | 管理各供应商 Key，按题型选模型（按厂商分组） |
|  系统设置 | 答题间隔、最大 Token、提示词、重置统计 |
|  使用说明 | 使用指南与注意事项 |
|  脚本信息 | 当前版本、免责声明、项目地址 |

> 模型配置里点「测试」时，**整张厂商卡片**会变淡绿（成功）或淡红（失败）。

## 支持题型

单选题 · 多选题 · 判断题 · 填空题 · 简答题（含图片）

---

## 使用技巧

- **答题间隔** 建议 1500–3000ms，避免请求过快被限流
- **题型策略**：判断 / 单选可用便宜模型，简答 / 填空用强模型
- **自动保存**：题目与答案自动入库，可在「题目导出」查看
- **自定义提示词**：在「系统设置」中调整以引导更准答案
