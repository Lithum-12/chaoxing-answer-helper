# 学习通自动答题助手 Next

**Tampermonkey 脚本，无需安装任何环境。**

> 抓取学习通题目 → 调用 AI 自动作答。支持多家供应商、按题型选模型、答题记录导出与 Token 统计，配可拖动的悬浮工具球与实时日志。

> 由 [long-0000/chaoxing-answer-helper](https://github.com/long-0000/chaoxing-answer-helper) Fork，本仓库为二次开发版（Next）。

---

## 安装

### 1. 安装 Tampermonkey

| 浏览器 | 方式 |
|--------|------|
| Edge | 应用商店搜索 **Tampermonkey** |
| Chrome | Chrome 网上应用店搜索 **Tampermonkey** |
| Firefox | 附加组件搜索 **Tampermonkey** |

### 2. 添加脚本

1. 打开 Tampermonkey → **添加新脚本**
2. 删除默认内容，粘贴 `chaoxing-answer.user.js` **全部内容**
3. `Ctrl+S` 保存

## 快速开始

| 步骤 | 操作 |
|------|------|
| ① | 打开学习通作业 / 考试页面 |
| ② | 右上角出现蓝色圆形**悬浮按钮**，鼠标悬停或点击 → 向下展开菜单 |

## 字体反爬解码器（可选配套脚本）

学习通对**课程内的章节小测 / 学生学习页**启用了字体反爬：题干里的部分汉字被换成生僻码点、再用自定义字体（`font-cxsecret`）渲染，屏幕看着正常、脚本抓到的却是乱码，导致 AI 答错。**独立的作业 / 考试页无此加密**，主脚本即可正常作答。

要支持加密页，再装一个**配套解码器**：

1. 打开 Tampermonkey → **添加新脚本**，粘贴 `cx-font-decoder.user.js` 全部内容并保存；
   或直接访问安装链接（jsDelivr CDN）：
   `https://cdn.jsdelivr.net/gh/Lithum-12/chaoxing-answer-helper@main/cx-font-decoder.user.js`
2. 装好后无需任何设置，主脚本会自动检测并调用它还原题干。

- 未安装时，遇到加密题主脚本会**弹提示并给出安装入口**，跳过这些题；其它页面不受影响。
- 解码器内置字形 hash 映射表，**完全离线**、不联网、不需要额外模型；超星基准字体多年未变，一般无需更新。
- 判断是否装好：控制台 → **脚本信息**，装有解码器时会显示「🧩 扩展脚本信息」（版本与映射表条数）。

## 界面

### 悬浮按钮（FAB）

右上角圆形按钮，向下展开为竖排菜单：

| 按钮 | 说明 |
|------|------|
| 开始答题 | 启动自动答题 |
| 停止 | 中断当前流程 |
| 调试 | 查看题目抓取情况（不自动填写） |
| 更多 / 设置 | 打开控制台 |

按钮带进度徽标与状态点（绿=正常 / 黄=进行中 / 红=错误）。

### 实时日志浮窗

有日志输出时，**右下角自动弹出**深色日志框，实时显示运行信息；点 `×` 关闭，直到下一条日志到来才会再次出现。

### 控制台标签页

| 标签页 | 功能 |
|--------|------|
|  仪表盘 | 总 Token、答题数、预估费用，含环形图与折线图（悬停看明细） |
|  Token 分析 | 输入 / 输出 Token 明细 |
|  题目管理 | 导出答题记录（JSON / CSV / TXT / HTML），并可**导入**之前导出的 JSON 合并入库 |
|  模型配置 | 管理各供应商 Key，按题型选模型，选择会话 / 批量模型 |
|  系统设置 | 答题间隔、温度、最大 Token、批量逐题填写开关、提示词、恢复默认 / 重置统计 |
|  控制台 | 运行日志，含「清屏」与「关闭 / 开启迷你面板」 |
|  脚本信息 | 版本、供应商 / 模型数、答题模式、许可证、项目地址；装有解码器时附「扩展脚本信息」 |

> 模型配置里点「测试」时，**整张厂商卡片**会变淡绿（成功）或淡红（失败）。

## 使用技巧

- **答题间隔** 建议 1500–3000ms，避免请求过快被限流
- **题型策略**：判断 / 单选可用便宜模型，简答 / 填空用强模型
- **自动保存**：题目与答案自动入库，可在「题目管理」查看 / 导出 / 导入
- **自定义提示词**：在「系统设置」中调整以引导更准答案
